### Sobre Mí

</div>

Soy **Backend Developer con Python**. Me estoy formando siguiendo el [roadmap de Backend de roadmap.sh](https://roadmap.sh/backend), con un proyecto publicado por cada tema.

Empecé por los fundamentos usando solo la librería estándar, antes de pasar a frameworks: aplicaciones de línea de comandos, persistencia de datos, consumo de APIs REST, manejo de errores y pruebas automatizadas.

Me enfoco en escribir código claro y separado por capas, validar las entradas, manejar los errores sin que el usuario vea un traceback y cubrir cada proyecto con tests. Trabajo con Git usando **Conventional Commits** y un commit por cada funcionalidad.
